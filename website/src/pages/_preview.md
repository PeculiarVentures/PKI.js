# PKIjs — X.509, CMS, and other PKI formats for JavaScript

Create, parse, sign, and verify certificates, CRLs, OCSP messages, CMS messages, timestamps, and PKCS#12 files in browsers and Node.js. PKIjs is written in TypeScript, relies on the Web Crypto API for all cryptography, and is built on [asn1js](https://asn1js.org).
