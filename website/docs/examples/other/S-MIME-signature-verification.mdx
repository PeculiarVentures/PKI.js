# S/MIME signature verification

Verify a signed email: split the multipart/signed message into the signed part and its detached CMS signature, check the signature, and check that the signer's certificate chains up to a root you trust.

The sample is a message signed by a sample CA. To check your own, save a signed email as an `.eml` file (most mail clients can) and choose it below, with the root certificate of its signer. Everything runs in your browser: the files are not uploaded anywhere.
