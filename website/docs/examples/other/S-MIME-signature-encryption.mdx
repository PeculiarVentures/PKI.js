# S/MIME encryption

Encrypt an email for a recipient's certificate: wrap the message in a MIME entity, encrypt it as CMS EnvelopedData, and put it in an `application/pkcs7-mime` message. Then decrypt it as the recipient. Edit the message below, run the example, and download the encrypted `.eml` file.
